# Project Statement

## Project Title
College Lab Equipment Manager

## Problem Statement

Managing college laboratory equipment manually can be difficult when there are many different equipment items and quantities to keep track of. Finding a particular piece of equipment can also take time.

The College Lab Equipment Manager provides a simple Python-based solution for maintaining basic laboratory equipment records.

## Proposed Solution

The College Lab Equipment Manager is a menu-driven Python application. It allows the user to add equipment with its quantity, view the equipment currently stored in the system, and search for a particular equipment item.

## Project Objectives

- To maintain a simple record of laboratory equipment.
- To add equipment and its quantity.
- To view available equipment.
- To search for specific equipment.
- To apply basic Python programming concepts to a practical problem.
- To understand modular programming by separating functions into different Python files.

## Current Modules

### 1. main.py
Controls the main menu and connects the different modules.

### 2. add_equipment.py
Allows the user to enter an equipment name and quantity and add it to the equipment list.

### 3. view_equipment.py
Displays all equipment currently stored in the system along with their quantities.

### 4. search_equipment.py
Allows the user to search for a particular equipment by name and displays its details if it is available.

## Technologies Used

- Python
- GitHub

## Scope

The current version focuses on basic laboratory equipment management during a program session. Equipment data is stored in memory while the program is running.

In the future, the project can be enhanced by adding:

- Update equipment functionality
- Delete equipment functionality
- Permanent data storage using files or a database
- Equipment issue and return tracking
- User login and authentication
- Graphical User Interface (GUI)
- Equipment reports

## Expected Outcome

The project provides a simple and beginner-friendly way to manage basic laboratory equipment records. It demonstrates the use of Python functions, lists, dictionaries, loops, conditional statements, user input, and modules to solve a practical problem.
