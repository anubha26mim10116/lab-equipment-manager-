College Lab Equipment Manager

Problem Statement

Managing laboratory equipment manually can be difficult when there are many different types of equipment and quantities to keep track of. A simple computerized system can make this process easier.

Proposed Solution

The College Lab Equipment Manager is a Python-based menu-driven application that helps users maintain basic records of laboratory equipment.

Main Features

- Add new equipment
- View all available equipment
- Search for equipment
- Delete equipment
- Exit the program

Programming Concepts Used

- Variables
- Lists
- Dictionaries
- Input and output
- Conditional statements
- Loops
- Menu-driven programming

Future Enhancements

The project can be improved by adding:

- Update equipment functionality
- File handling for permanent data storage
- Database connectivity
- Equipment issue and return tracking
- Login system
- Graphical user interface (GUI)
